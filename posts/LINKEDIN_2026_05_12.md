I built a markdown prompt that runs a cost-aware routing swarm: one GitHub Copilot premium request dispatches 4–8 independent subagents inside the same message, each routed to the cheapest model that does the job.

Cheap models for cheap work; frontier only for the synthesis pass. Each subagent writes one HMAC-signed JSONL line, so the audit log is tamper-evident.

It's MIT-licensed, no telemetry, no sign-up.

If you don't already use an LLM agent harness in your workflow, this won't matter to you today. If you do, the bones of this are mostly free, because most coding-agent harnesses bill by the parent message, not by the fan-out inside it.

The cost ratio sits around 100×–1000× cheaper than running the same work as raw API calls, depending on which frontier model you'd otherwise pay for. Don't take my number; there's a calculator in the repo so you can measure your own.

Multi-platform: the routing pattern works on Copilot Pro+ (current pricing window, highest leverage), on free vendor mesh (OpenRouter, Groq, Together, Cerebras), on Claude Code, and anywhere a parent agent can launch subagents.
